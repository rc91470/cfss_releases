# CFSS v4.4.1 Installation Guide

## Windows Installation

### Option 1: Direct Executable (Recommended)
1. Download `CFSS_v4.4.1_Windows.exe`
2. Run the executable directly - no installation required
3. The app will create necessary folders on first run
4. Auto-updater will handle future updates

### Option 2: Package Installation  
1. Download `CFSS_v4.4.1_Windows_2025-08-13_14-15-44.zip`
2. Extract to your desired location
3. Run `CFSS_v4.4.1_Windows.exe` from the extracted folder
4. Keep the sounds/ and data/ folders with the executable

## Auto-Updater Notes
- The enhanced auto-updater in v4.4.1 will automatically:
  - Detect missing sounds/ and data/ folders
  - Restore critical components if they're missing
  - Validate update integrity before installation
  - Preserve all your scan data during updates

## Upgrading from Older Versions
- Your existing scan data and settings will be preserved
- The auto-updater will detect v4.4.1 automatically
- **Important**: v4.4.1 fixes critical serial number bugs - update as soon as possible

## Troubleshooting
- If you see Windows popups about missing sounds: v4.4.1 fixes this automatically
- If auto-updater doesn't detect the update: Check your internet connection and restart the app
- For any issues, see the [full troubleshooting guide](../documentation/WINDOWS_TROUBLESHOOTING.md)

## System Requirements
- Windows 10/11 (64-bit)
- 100MB free disk space
- Internet connection for auto-updates
- No additional dependencies required
