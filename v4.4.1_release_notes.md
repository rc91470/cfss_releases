# CFSS v4.4.1 - Critical Bug Fix Release

## 🚨 CRITICAL FIX
- **Fixed serial number synchronization** between save and display functions
- Resolves data inconsistency issues in scan results where displayed data differed from saved data

## 🔄 Auto-Updater Enhancements  
- **Enhanced component validation** - Automatically detects and restores missing files
- **Sounds folder validation** - Fixes Windows popup issues with proper audio feedback
- **Improved ZIP file handling** - Better update file management and extraction
- **Missing component detection** - Restores critical folders (sounds/, data/) automatically
- **Better error handling** - Improved user feedback during updates

## 🖥️ Platform Support
- **Windows**: v4.4.1 (Latest with all fixes)
- **macOS**: v4.2.4 (Stable, fully compatible)

## 🔧 Installation
1. Download the appropriate version for your platform
2. For Windows: Run `CFSS_v4.4.1_Windows.exe` directly
3. For macOS: Extract and follow installation instructions in the package
4. The auto-updater will handle future updates automatically

## ⚠️ Important Notes
- **Windows users**: This release fixes critical serial number bugs - update immediately
- **Auto-updater compatibility**: Older versions will auto-detect this release
- **Data preservation**: All scan data and settings are preserved during updates
- **macOS users**: v4.2.4 remains the latest stable macOS release

## 🛠️ Technical Details
Built with enhanced auto-updater system that validates component integrity and automatically restores missing files. This release specifically addresses serial number synchronization issues that could cause inconsistencies between displayed scan results and saved data files.
