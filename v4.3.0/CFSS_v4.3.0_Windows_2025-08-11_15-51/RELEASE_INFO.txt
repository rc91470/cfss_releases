CFSS v4.3.0 - Windows Release  
================================  
  
Release Date: August 11, 2025  
Version: 4.3.0 (Production Release)  
Platform: Windows 64-bit  
  
Key Features in v4.3.0:  
- Extended CSW circuit special rules to XSR circuits  
- XSR circuits now follow same length-based display logic as CSW  
- Fixed save results to use correct serial for XSR circuits
