# CFSS v4.3.0 Release Notes

**Release Date:** January 2025  
**Version:** 4.3.0  
**Build:** Production Release

## What's New in v4.3.0

### 🆕 Enhanced Circuit Processing Rules
- **XSR Circuit Support**: Extended existing CSW circuit special rules to also apply to XSR circuits
- **Unified Processing**: XSR circuits now follow the same length-based display and serial selection rules as CSW circuits
- **Consistent Sorting**: XSR circuits use the same natural sorting algorithms as CSW circuits

### 📋 Key Improvements
- **Circuit Display Rules**: XSR circuits now display with appropriate length-based logic
- **Serial Selection**: XSR circuits follow the same serial selection rules as CSW circuits  
- **Data Processing**: Unified processing for both CSW and XSR circuit types

### 🛠 Technical Details
The following special rules now apply to both CSW and XSR circuits:
- Length-based display logic in circuit list
- Serial selection priorities for automated processing
- Natural sorting for consistent ordering

## Files Modified
- `cfss_app.py`: Extended CSW rules to include XSR circuits
- `circuit_manager.py`: Updated serial selection and sorting for XSR circuits
- Version files: Updated to v4.3.0

## Compatibility
- **Windows**: Fully supported
- **macOS**: Compatible (requires rebuild for distribution)
- **Data**: Backward compatible with existing project files

## Installation
1. Download the latest release from GitHub
2. Extract to desired location
3. Run `CFSS_v4.3.0.exe` (Windows)

## Upgrade Notes
- No special upgrade steps required
- Existing projects will automatically benefit from XSR circuit enhancements
- All previous v4.2.x features remain available
