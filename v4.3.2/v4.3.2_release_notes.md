# CFSS v4.3.2 Release Notes

## Testing Release for Auto-Updater Fix

This is a testing release to validate the auto-updater restart functionality.

### Changes from v4.3.1
- Updated version number to 4.3.2 for testing purposes
- Same functionality as v4.3.1 with fixed auto-updater

### Auto-Updater Improvements (from v4.3.1)
- ✅ Fixed infinite update loop issue
- ✅ Properly backs up old executable before deletion
- ✅ Correctly restarts with newly extracted versioned executable
- ✅ Maintains version numbers in filenames for better tracking
- ✅ Enhanced logging for debugging update process

### Testing Purpose
This version allows testing the update process from v4.3.1 → v4.3.2 to ensure:
- Update notification appears correctly
- Download process works
- Restart process launches the correct new version
- No more infinite update loops

### XSR Circuit Support (carried from v4.3.0)
- Extended CSW circuit rules to XSR circuits
- Unified display logic for XSR multi-jumper circuits
- Correct serial selection for XSR save results
- All previous features maintained
