# CFSS v4.4.5 Release Notes

## Enhanced Windows High-DPI Scaling with Optimized UI Element Widths

### New Features & Improvements

**🖥️ Enhanced Windows DPI Support**
- Improved high-DPI scaling detection using Windows SetProcessDpiAwarenessContext API
- Comprehensive fallback mechanisms for various DPI configurations
- Better support for mixed-DPI and multi-monitor setups

**📐 Optimized UI Element Sizing**
- Window width optimized to 650px for high-DPI displays (down from 840px)
- Skip reason dropdown expanded to 300px width to fit longest text options
- Circuit/jumper dropdowns set to reasonable 100px width for better layout
- Search entry doubled to 200px width for better usability
- Serial entry extended to 150px width for improved visibility
- All button widths normalized to 100px for consistency

**🎯 User Experience**
- Fixed issue where "reason for skipping dropdown" text was truncated
- Better proportioned interface that fits properly on high-DPI screens
- Resolved problems with buttons being cut off at bottom of window
- Improved overall layout balance and visual consistency

### Technical Details
- Enhanced DPI detection with proper Windows API integration
- Smart scaling factors with minimum boost for slightly higher DPI displays
- Better scaling thresholds: 1.1x for 125%, 1.3x for 150%, 1.6x for higher DPI
- Cap at 2.5x scaling for extreme DPI cases

### Files Included
- `CFSS_v4.4.5_Windows.exe` - Main application executable
- `data/` - CSV data directory
- `sounds/` - Audio feedback files
- `v4.4.5_release_notes.md` - This file

### Installation
1. Extract the ZIP file to your desired location
2. Run `CFSS_v4.4.5_Windows.exe`
3. The application will create necessary data directories on first run

### System Requirements
- Windows 10 or later
- .NET Framework (typically pre-installed)
- Minimum 4GB RAM recommended
- 100MB free disk space
